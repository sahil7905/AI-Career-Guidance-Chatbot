# Data Science and Machine Learning Careers
Roles: Data Analyst, Data Scientist, Machine Learning Engineer, AI Engineer, MLOps Engineer. Data Analysts focus on SQL, Excel, Power BI or Tableau and statistics. Data Scientists add Python, pandas, scikit-learn, statistics, experimentation and storytelling. ML Engineers add deep learning with PyTorch or TensorFlow, model deployment, APIs, Docker and cloud. AI Engineers build LLM applications using prompt engineering, RAG, vector databases and agents.
Core skills: Python, SQL, statistics, linear algebra, machine learning, feature engineering, data visualisation, communication. Roadmap: learn Python and SQL first, then statistics, then scikit-learn, then deep learning, then deployment. Resources: Andrew Ng Machine Learning Specialization (Coursera), Kaggle Learn, fast.ai, Hands-On Machine Learning by Aurelien Geron, Hugging Face course, DeepLearning.AI short courses on LLMs. Projects: house price prediction, customer churn model, resume screener, RAG chatbot over documents, sentiment analysis dashboard.
