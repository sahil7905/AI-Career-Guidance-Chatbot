# Cybersecurity Careers
Roles: SOC Analyst, Penetration Tester, Security Engineer, Cloud Security Engineer, GRC Analyst, Digital Forensics Analyst. Core skills: networking (TCP/IP, DNS, HTTP), Linux, operating system internals, cryptography basics, web security (OWASP Top 10), scripting in Python, SIEM tools such as Splunk, incident response, risk and compliance.
Roadmap: learn networking and Linux, then security fundamentals, then hands-on labs, then a certification, then specialise in blue team, red team or GRC. Certifications: CompTIA Security+, CEH, eJPT, OSCP for advanced pentesting, CISSP for experienced professionals. Resources: TryHackMe, Hack The Box, PortSwigger Web Security Academy, OWASP documentation, Cybrary. Projects: home lab with vulnerable machines, log analysis with a SIEM, web vulnerability report, simple port scanner in Python.
