# Software Development Careers
Roles: Frontend Developer, Backend Developer, Full Stack Developer, Mobile Developer, Software Engineer, QA Automation Engineer. Frontend uses HTML, CSS, JavaScript, React. Backend uses Java with Spring Boot, Python with Django or FastAPI, Node.js, REST APIs, databases like PostgreSQL and MongoDB. Full stack combines both. Mobile uses Kotlin, Swift or Flutter.
Core skills: data structures and algorithms, object oriented programming, SQL, Git and GitHub, API design, testing, system design basics, clean code. Roadmap: master one language, practise DSA daily on LeetCode or GeeksforGeeks, build three full projects, learn Git, then learn system design. Resources: CS50 by Harvard, freeCodeCamp, The Odin Project, Cracking the Coding Interview, NeetCode roadmap, Spring Boot documentation. Projects: e-commerce site, task manager with authentication, REST API with database, chat application.
