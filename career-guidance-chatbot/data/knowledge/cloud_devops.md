# Cloud and DevOps Careers
Roles: Cloud Engineer, DevOps Engineer, Site Reliability Engineer, Cloud Architect, Platform Engineer. Core skills: Linux, networking, scripting in Bash or Python, Git, CI/CD with Jenkins or GitHub Actions, Docker, Kubernetes, Terraform, monitoring with Prometheus and Grafana, and one cloud provider: AWS, Azure or Google Cloud.
Roadmap: learn Linux and networking, then Git and scripting, then Docker, then a cloud provider, then Kubernetes and Terraform, then CI/CD projects. Certifications: AWS Cloud Practitioner then AWS Solutions Architect Associate, Microsoft AZ-900 and AZ-104, Certified Kubernetes Administrator, HashiCorp Terraform Associate. Resources: KodeKloud, A Cloud Guru, AWS Skill Builder, Linux Foundation courses, The Phoenix Project book. Projects: CI/CD pipeline for a web app, deploy containers on Kubernetes, infrastructure as code for a VPC.
